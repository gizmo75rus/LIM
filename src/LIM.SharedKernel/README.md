# LIM.SharedKernel

## Описание

LIM.SharedKernel - это ядро общей бизнес-логики и инфраструктуры проекта LIM (Laboratory Information Management). Этот проект содержит общие компоненты, которые используются во всех частях системы, включая доменные сущности, интерфейсы, базовые классы и общую инфраструктуру.

## Назначение

Проект LIM.SharedKernel служит центральным хранилищем общих элементов для всей системы:

1. **Доменные сущности** - общие модели данных и бизнес-объекты
2. **Интерфейсы** - абстракции для взаимодействия между слоями
3. **Базовые классы** - общие реализации для различных компонентов
4. **Общая инфраструктура** - базовые сервисы и компоненты, используемые во всех частях системы

## Зависимости

### Внешние библиотеки
- **Autofac** (v6.5.0) - контейнер внедрения зависимостей
- **Microsoft.Extensions.Configuration.Abstractions** (v6.0.0) - абстракции конфигурации
- **Rebus** (v6.7.0) - инфраструктура для асинхронной коммуникации
- **Rebus.Autofac** (v8.0.0) - интеграция Rebus с Autofac
- **Rebus.Events** (v4.0.2) - поддержка событий в Rebus
- **Rebus.RabbitMq** (v7.4.6) - транспорт RabbitMQ для Rebus
- **Rebus.Serilog** (v7.0.0) - интеграция Rebus с Serilog

## Архитектура

LIM.SharedKernel реализует следующую архитектурную структуру:
- Доменные сущности и значения
- Интерфейсы репозиториев
- Базовые классы для сервисов
- Общие исключения и ошибки
- Константы и настройки

## Использование

Проект предназначен для использования в других проектах системы LIM через ссылку на него. Все остальные проекты (ApplicationCore, Infrastructure, WebApi) могут использовать компоненты из этого проекта.

Для добавления ссылки в другой проект используйте:
```xml
<PackageReference Include="LIM.SharedKernel" Version="1.0.0" />
```

или

```bash
dotnet add reference LIM.SharedKernel.csproj
```
